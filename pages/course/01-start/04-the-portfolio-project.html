The portfolio project

Why this lesson is here. It names the separate repository the exercises write into, before any file is created.

A local Practice Shop supplies a searchable catalog, cart API, and cart lookup page. One application supports manual cases, coding exercises, UI/API checks, controlled defects, and CI. Create a separate playwright-ai-qa-portfolio repository outside this resume workspace, initially local or private.

Limits: in-memory carts and two public synthetic tokens. No real login, database, payments, or production security. Reading after a write proves in-process state, not restart durability. Do not publicly deploy this teaching server.

Add folders only as needed: lab/, exercises/, src/pages/, src/fixtures/, src/schemas/, tests/ui/, tests/api/, tests/e2e/, specs/, and docs/. Keep requirements, strategy, traceability, decisions, AI evidence, and results alongside the code.
