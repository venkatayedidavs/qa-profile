Which feature should I use?

Why this lesson is here. The decision table. Step 4 tells you to use it to choose instruction, skill, agent, or hook.

NeedSmallest useful choiceExample
One explanation or questionPlain promptExplain why string "2" differs from number 2.
A project conventionRepository instructionsUse the agreed contract as the oracle.
A rule for particular filesScoped instructionsTest changes must include a negative case.
A repeated procedureSkillReview a requirement and produce traceable test cases.
A specialist role with fewer toolsCustom agentReview code without editing or running commands.
A bounded delegated investigationSubagentReturn coverage gaps to the main agent.
Code must run at an agent eventHookRequire a decision before a tool call.
Access an external capabilityMCP, built-in tool, or extensionRead an authorized issue from a tracker.
Distribute reusable customizationsAgent pluginBundle a reviewed skill for another practice project.

How they fit: you give a task; the harness assembles instructions and context; a model may use a skill and request a tool; an applicable hook can intervene; the tool returns evidence; you review the result. A plugin can package some of these parts. None replaces the requirement.
