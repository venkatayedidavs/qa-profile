AI basics: start here

Why this lesson is here. The AI page opens with pace, outcomes, and the main track, before any customization is built.

For a tester or developer who has heard the names but is not sure how they fit together. No machine-learning mathematics, model training, API key, or previous agent experience is assumed. Begin with plain-language concepts; then build small customizations in a separate practice folder.

Main track: VS Code with GitHub Copilot. General ideas transfer to other products, but file locations, settings, tool names, and hook formats do not always transfer. A custom agent is not a newly trained model.

Pace: 24 steps in six phases, not 24 days. Start with vocabulary, then context and instructions, skills, agents, hooks, and integrations. Repeat a step until you can explain its result. The hook script is supplied; the goal is understanding its inputs and decisions, not memorizing JavaScript.

Learning outcomes

  • Explain model, prompt, context, tool, agent, skill, hook, MCP, and plugin without treating them as synonyms.
  • Choose the smallest customization for a QA or development task.
  • Create and inspect working examples using only synthetic practice data.
  • Verify generated work, investigate missing context, and bound tool permissions.
  • Distinguish AI-assisted testing from testing an AI product.
