Step 5: Async code and phase gate

Why this lesson is here. Browser and API calls return promises. This phase gate blocks UI tests until you can explain await.

Outcome: explain Promise and await. A Promise represents work with a result not immediately available.

Study: async JavaScript and async functions.

exercises/inspect-api.ts

async function readCatalog(): Promise<unknown> {
  const response = await fetch('http://127.0.0.1:3100/api/products?q=NOTEBOOK');
  if (!response.ok) throw new Error(`Request failed: ${response.status}`);
  const body: unknown = await response.json();
  return body;
}

const pending = readCatalog();
console.log(pending instanceof Promise);
console.log(await pending);

Pass when: connect request, Promise, resolved value, and failure in your own words.
