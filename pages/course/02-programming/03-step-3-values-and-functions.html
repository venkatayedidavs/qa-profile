Why this lesson is here. The page teaches plain JavaScript before types, because the compiler errors in the next step only make sense after string and number are distinct.

Outcome: read JavaScript before types. String "2" differs from number 2; === does not convert types.

Study: MDN variables and functions.

exercises/total.js

function lineTotal(priceCents, quantity) {
  return priceCents * quantity;
}

const total = lineTotal(1200, 2);
console.log(total);
console.log(total === 2400);
console.log('2' === 2);

Pass when: explain inputs, return values, booleans, and an error yourself.
