Build a skill

Phase 3 of the AI page. A skill is a procedure folder, ordered after instructions and before a custom agent.

Why this module is here. Phase 3 of the AI page. A skill is a procedure folder, ordered after instructions and before a custom agent.

What it unlocks. Build a custom agent. The Phase 3 gate is the entrance to that module.

Prerequisite: a passing practice lab and understood instructions. Outcome: a reusable, evidence-based procedure with a tested discovery path.

  1. Lesson 1 Step 9: Write the skill's procedure

    The procedure is written before supporting files. A skill is not a new model.

  2. Lesson 2 Step 10: Add one useful supporting resource

    One supporting resource is added only after the procedure exists.

  3. Lesson 3 Step 11: Invoke it and verify discovery

    Discovery is evidence the files are wired, which you cannot check before they exist.

  4. Lesson 4 Step 12: Evaluate the skill, including failures

    The phase gate evaluates the skill, including failures, after a real invocation.
