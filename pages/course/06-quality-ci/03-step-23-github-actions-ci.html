Step 23: GitHub Actions CI

Progress is saved in this browser.

0%

Why this lesson is here. GitHub Actions runs the suite you can already run locally, with the same Node major.

Outcome: same gates on a clean runner. CI is not deployment.

Study: Playwright CI, Actions.

.github/workflows/playwright.yml. webServer starts the local app without real secrets or model calls. Action versions match the checked official example.

name: QA checks
on:
  push:
    branches: [main]
  pull_request:
  workflow_dispatch:

permissions:
  contents: read

jobs:
  quality:
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@v6
      - uses: actions/setup-node@v6
        with:
          node-version: '22'
          cache: npm
      - run: npm ci
      - run: npm run typecheck
      - run: npm run lint
      - run: npx playwright install --with-deps
      - run: npm test
      - uses: actions/upload-artifact@v4
        if: ${{ !cancelled() }}
        with:
          name: playwright-report
          path: playwright-report/
          retention-days: 7

Pass when: same revision passes locally/CI, a known failure fails the job. Local execution alone does not prove GitHub runner success.
