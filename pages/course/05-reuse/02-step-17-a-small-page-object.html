Step 17: A small page object

Progress is saved in this browser.

0%

Why this lesson is here. The page says to add a page object for real repetition, after the fixture, and to keep business assertions visible.

Outcome: extract repeated actions, keep assertions in tests. A class groups behavior/data; constructor receives the page.

Study: page objects, not a large inheritance framework.

src/pages/catalog-page.ts

import type { Locator, Page } from '@playwright/test';

export class CatalogPage {
  readonly searchInput: Locator;
  readonly searchButton: Locator;

  constructor(page: Page) {
    this.searchInput = page.getByLabel('Search products');
    this.searchButton = page.getByRole('button', { name: 'Search', exact: true });
  }

  async search(query: string): Promise<void> {
    await this.searchInput.fill(query);
    await this.searchButton.click();
  }
}
