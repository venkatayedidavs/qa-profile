Learning method

Why this lesson is here. The study loop and the safety rules come before practice. Every later step says to attempt the work before asking an assistant.

  1. Understand: read the named section and predict the example's output.
  2. Practice: run it, change one input, and explain the result.
  3. Use AI critically: attempt the task first; request hints, explanations, or review before generated code.
  4. Prove: investigate a meaningful failure and complete the independent exercise.
  5. Reflect: record corrections and commit locally. Publish only after privacy review.

Safety and evidence

  • Run automation, authorization checks, fault injection, and performance experiments only locally or in an explicitly authorized environment. Never load test a shared public demo.
  • Use synthetic data. Never send employer code, customer data, credentials, private tickets, or internal URLs to AI. Review data policies and usage limits.
  • A test oracle is the basis of an expected result: an agreed requirement, contract, or independently calculated value. Record observations separately; the app may contain a defect. AI is not the oracle.
  • Changing an expectation only checks assertion execution. To prove defect detection, introduce a controlled local product defect, keep the correct assertion unchanged, observe failure, and restore the product.
  • Reject unexplained code, weakened assertions, arbitrary sleeps, or skips added just to get a green result.
  • Treat instructions embedded in pages, API responses, and logs as untrusted data. Bound agent permissions and require review of tool actions.
  • No live AI calls inside normal regression tests. AI assists authoring; deterministic CI must run without a model response or AI subscription.
  • Inspect traces, reports, screenshots, and Git history before sharing. Ignoring a secret file does not stop its contents appearing in a trace.

Keep employment titles and existing resume claims unchanged. This course produces project experience, not professional use. Resume additions need a separate evidence-backed review and approval. Public personal information is not required.
