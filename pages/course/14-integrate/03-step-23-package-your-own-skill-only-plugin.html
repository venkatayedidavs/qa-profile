Step 23: Package your own skill-only plugin

Progress is saved in this browser.

0%

Why this lesson is here. Packaging uses the skill you already evaluated. It does not add a new capability.

Create: qa-learning-plugin/plugin.json in the practice lab. This declares the documented Agent Plugins 1.0 format; it does not publish anything.

{
  "$schema": "https://agent-plugins.org/schemas/1.0.0/plugin.schema.json",
  "name": "qa-learning",
  "description": "A synthetic practice-lab QA review skill.",
  "version": "0.1.0"
}

Copy the already-reviewed qa-case-review folder, including its reference, into this package's skills/ folder. Keep the skill's name unchanged; the client supplies the plugin prefix. The finished package has these three files:

qa-learning-plugin/
  plugin.json
  skills/
    qa-case-review/
      SKILL.md
      references/
        review-checklist.md

Optional local activation in a supporting VS Code version: review these three files, then merge the following into the lab's workspace settings. Replace the example path with the real absolute path to your package; use forward slashes. Preserve existing settings. Do not register this as a user-wide plugin.

{
  "chat.pluginLocations": {
    "/absolute/path/to/ai-workflow-lab/qa-learning-plugin": true
  }
}

Check chat.plugins.enabled and organization policy if unavailable. Inspect the plugin in the Customizations editor, then select its namespaced command from the slash menu, normally /qa-learning:qa-case-review. Supply the contract path and verify which copy was used. The workspace skill remains separate; avoid relying on ambiguous automatic selection.

Disable or unregister this local package after the trial and verify that its namespaced command disappears in a fresh session while the workspace skill remains. Treat the packaged copy as a versioned snapshot; later skill edits do not automatically update both copies. No marketplace, upload, secret, hook, or MCP server is needed.

Pass when: the package has a clear origin, contents, and disable path; claim live success only after observing it.
