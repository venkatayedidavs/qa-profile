Explain it without AI

Why this lesson is here. The original page ends the teaching with questions you answer out loud before you open the comparison.

Answer first: Is a skill a trained model? Can a hook replace a test? Does read-only mean private? Is every tool MCP? Does a discovered skill always run? Is testing a model the same as asking it to write tests?

Compare your explanations
  1. A skill supplies a reusable workflow and resources during use; it does not update model weights.
  2. A hook reacts to its runtime's events. Deterministic tests still check behavior, and CI can enforce release or merge gates independently of chat.
  3. Read-only restricts modifications through exposed tools, not what read data a remote model receives.
  4. Tools can be built into the product, supplied by extensions, or exposed by an MCP server.
  5. Discovery makes a skill available. Invocation and correct execution require separate evidence.
  6. AI-assisted testing helps you test ordinary software; AI-product testing evaluates model-powered behavior and its surrounding software.
