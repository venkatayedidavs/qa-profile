Official sources and verification

Why this lesson is here. The verification notes and the evidence boundary stay last, as on the original page.

Research checked on 30 September 2026. These are primary product docs and security guidance, not a promise that every installed version or account exposes the same features. The examples are original teaching examples. Consult the linked runtime reference when a UI or schema differs.

  • Understanding language models: models versus tools, finite context, compaction, and usage.
  • VS Code customization overview: discovery, scopes, verification, and migration.
  • Custom instructions and prompt files: activation and Local/Agent Host differences.
  • Agent Skills: name and directory rules, metadata, references, and invocation.
  • Custom agents, Copilot tool aliases, and subagents: role configuration and delegation.
  • Hook configuration, Local event schema, and Copilot event schema: use the reference for the selected harness.
  • Agent plugins: package formats, local registration, enablement, and implicit trust of bundled MCP servers.
  • MCP architecture and VS Code tools: integration vocabulary and capability selection.
  • Prompting and text generation and Microsoft RAG overview: context, grounding, and limitations.
  • OWASP prompt injection guidance: untrusted content, least privilege, and layered mitigation.
  • Evaluation best practices: representative tasks, human criteria, variability, and regression evaluation.
  • Node.js test runner: the local, dependency-free executable checks.

Evidence boundary: local script tests can verify the supplied code and formats. They cannot prove Copilot invocation, editor hook activation, plugin discovery, model quality, or an organization's policies. The live exercises require your observations in the selected client; record unavailable checks honestly.
