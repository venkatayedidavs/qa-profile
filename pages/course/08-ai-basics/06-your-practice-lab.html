The independent contract

specs/quantity.md. A small standalone extraction of the Practice Shop quantity rule. No HTTP status, UI, stock, or ownership behavior is implemented here.

## Quantity contract

- QTY-01: Accept JavaScript numbers that are integers from 1 to 5 inclusive.
- QTY-02: Reject every other input without coercing its type.
- QTY-03: Return a boolean; do not change the input or external state.

Examples: 1, 3, and 5 return true.
Examples: 0, 6, "2", 2.5, null, and true return false.
Discounts, stock limits, HTTP responses, and UI text are out of scope.

src/quantity.mjs. The .mjs extension identifies a JavaScript module; export lets the test import the function.

export function isValidQuantity(quantity) {
  return Number.isInteger(quantity) && quantity >= 1 && quantity <= 5;
}

test/quantity.test.mjs. Expected values come from the contract, not from the function being tested.

import test from 'node:test';
import assert from 'node:assert/strict';
import { isValidQuantity } from '../src/quantity.mjs';

const cases = [
  { input: 1, expected: true },
  { input: 3, expected: true },
  { input: 5, expected: true },
  { input: 0, expected: false },
  { input: 6, expected: false },
  { input: '2', expected: false },
  { input: 2.5, expected: false },
  { input: null, expected: false },
  { input: true, expected: false },
];

for (const example of cases) {
  test(`quantity ${JSON.stringify(example.input)}`, () => {
    assert.equal(isValidQuantity(example.input), example.expected);
  });
}

Run from the lab root: node --test test/quantity.test.mjs. Expect 9 tests passed, 0 failed. Number.isInteger checks the type and whole-number condition; && requires all three checks. A passing suite proves these cases, not every possible property of the function.
