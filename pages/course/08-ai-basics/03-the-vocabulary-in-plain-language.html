The vocabulary, in plain language

Why this lesson is here. The page says to read the first group now and return to the others as later lessons introduce them.

Read the first group now. Return to the others as the lessons introduce them. The example throughout is a shopping-cart quantity rule, not a production AI system.

Models and conversations
Artificial intelligence (AI)
The broad field of computer systems performing tasks such as prediction, language processing, and decision-making. Not all AI generates text.
Machine learning (ML)
Learning patterns from data instead of specifying every decision as a handwritten rule. A spam classifier is one example.
Generative AI / LLM
Generative AI produces content. A large language model (LLM) is a model trained on large amounts of language data that can generate text and code. Some models also process images or other inputs.
Model / product / harness
The model produces responses; the product supplies the experience; the harness runs the agent loop, tools, and permissions. Changing the model does not change a hook's runtime format.
Session target / Agent Host
The session target selects the agent implementation, separately from the model. Local uses VS Code's extension-host agent; Copilot uses the shared Copilot runtime on Agent Host, the process that hosts that runtime. The same editor can therefore have different tool and hook behavior.
Training / inference / fine-tuning
Training learns model parameters. Inference uses a trained model. Fine-tuning further trains it on examples. Writing a skill or attaching a file supplies context; it does not fine-tune the model.
Prompt / prompt engineering
A request and its guidance; the practice of making them clear. Specify the task, relevant evidence, constraints, and expected output, then evaluate the result.
Token / context window
A token is a unit the model processes, often part of a word. The context window limits the information a model can handle in one request. A long chat is not unlimited memory.
Context engineering / compaction
Selecting useful instructions, files, history, and tool results for the current task. Compaction summarizes older context to make room; details can be lost. Keep important requirements in files.
Temperature / nondeterminism
Temperature controls sampling variation where supported. Lower temperature is not a truth switch or a guarantee of identical results. Some products do not expose this setting.
Latency / usage cost
How long a response takes and what model and tool usage consumes. Long context, retries, and subagents can add time and cost. Check the product's current allowance rather than assuming a fixed price per prompt.
Workflows and customization
Tool / function calling
A capability exposed to an agent, such as reading a file or running a test. The model requests a call; the application validates and executes it subject to permissions. A sentence saying "I ran it" is not a tool result.
Agent / agentic workflow
A model-driven loop that chooses actions, uses tools, observes results, and continues toward a goal. More autonomy needs clearer boundaries, not more trust.
Custom agent / subagent / handoff
A custom agent is a reusable role and tool configuration. A subagent performs a delegated task in a separate context. A handoff switches the active role with relevant context; it is not the same as delegation.
Instructions / prompt file
Instructions supply persistent project or task guidance. A prompt file is a saved task request invoked manually in supporting clients. In current VS Code docs, prompt files are Local-only compatibility material; skills are the forward path.
Agent Skill
A folder with a SKILL.md workflow and optional supporting files. It supplies a repeatable procedure, not a new model, a permission grant, or proof that the procedure was followed.
Hook
Code run by the harness at an event such as before a tool call. The code can make a predictable decision, but only if that hook is loaded and invoked. An agent hook is different from a Git pre-commit hook or a test framework's beforeEach.
MCP
Model Context Protocol: a standard for an AI application to communicate with servers offering tools, resources, and prompts. It is an integration protocol, not an AI model or an automatic security boundary.
Agent plugin / editor extension
An agent plugin packages supported customizations for reuse. A VS Code extension extends the editor and may contribute AI tools too. The terms overlap in purpose but describe different packaging systems.

Read: VS Code customization guide and MCP architecture.

Grounding, safety, and QA
Grounding / RAG
Grounding connects an answer to supplied evidence. Retrieval-augmented generation (RAG) retrieves relevant material and uses it during generation. Retrieval can miss the right rule or return an obsolete one; citations still need checking.
Embedding / vector search
An embedding represents data as numbers for tasks such as similarity search. Similar meaning is not the same as factual correctness, authorization, or the latest version.
Hallucination
An unsupported or false generated claim. In QA, it might be an invented requirement, package API, or test result. Ask for evidence and verify it independently.
Prompt injection
Input attempts to redirect the assistant away from its intended task. Instructions hidden in a page, ticket, or tool result are still untrusted content. Delimiters and warnings help but do not guarantee protection.
Least privilege / human approval
Expose only the capabilities and data needed. Review a consequential action before it runs. A "read-only" role can still send read content to a remote model; read-only is not private.
Test oracle / synthetic data
An oracle is the independent basis of an expected result, such as an agreed rule. Synthetic data is invented practice data with no real customer identity. The model's answer is not the oracle.
Evaluation (eval) / regression
An eval measures AI behavior against representative tasks and explicit criteria. A regression is a loss of previously acceptable behavior. Keep deterministic code tests as well as AI evals; they answer different questions.
False positive / false negative
A reviewer reporting a nonexistent bug is a false positive; missing a real bug is a false negative. Measure both rather than rewarding the longest list of findings.
AI-assisted testing / testing AI
Using an assistant to help test a normal function is AI-assisted testing. Evaluating a model-powered feature tests AI behavior itself. This course starts with the former.

Read: Microsoft on RAG, OWASP on prompt injection, and evaluation principles.
