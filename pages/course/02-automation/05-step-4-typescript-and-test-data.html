Why this lesson is here. A type. Types come after values. The page says advanced generics can wait.

Outcome: objects, arrays, loops, compiler errors versus runtime. Types do not automatically validate server JSON.

Study: everyday types; advanced generics can wait.

exercises/cart-data.ts

type Product = { name: string; priceCents: number };

function lineTotal(product: Product, quantity: number): number {
  return product.priceCents * quantity;
}

const notebook: Product = { name: 'Notebook', priceCents: 1200 };
const quantities: number[] = [1, 2, 5];
for (const quantity of quantities) {
  console.log(lineTotal(notebook, quantity));
}
