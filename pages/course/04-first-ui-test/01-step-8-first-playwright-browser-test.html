Step 8: First Playwright browser test

Why this lesson is here. Write the first Playwright test from the case and the page notes. AI may suggest locators.

Outcome: translate setup/actions/assertions. Playwright supplies isolated pages and retries web assertions until success or timeout.

Study: writing tests, webServer.

playwright.config.ts. Non-overlapping projects prevent duplicate API execution across browsers. Request-only tests launch no browser. Stop your manual server; this config starts a fresh one.

import { defineConfig, devices } from '@playwright/test';

const baseURL = 'http://127.0.0.1:3100';

export default defineConfig({
  testDir: './tests',
  fullyParallel: true,
  forbidOnly: Boolean(process.env.CI),
  retries: 0,
  workers: 2,
  reporter: [
    ['list'],
    ['html', { open: 'never' }],
    ['json', { outputFile: 'test-results/results.json' }],
  ],
  use: { baseURL, trace: 'retain-on-failure', screenshot: 'only-on-failure' },
  webServer: {
    command: 'npm run start:lab',
    url: `${baseURL}/health`,
    reuseExistingServer: false,
    stdout: 'pipe',
  },
  projects: [
    { name: 'api', testMatch: '**/api/**/*.spec.ts' },
    { name: 'ui-chromium', testMatch: '**/ui/**/*.spec.ts',
      use: { ...devices['Desktop Chrome'] } },
    { name: 'e2e', testMatch: '**/e2e/**/*.spec.ts',
      use: { ...devices['Desktop Chrome'] } },
  ],
});

tests/ui/search.spec.ts. Expected count and price come from the contract.

import { test, expect } from '@playwright/test';

test('CAT-02: search ignores case', { tag: ['@ui', '@smoke'] }, async ({ page }) => {
  await page.goto('/');
  const catalog = page.getByRole('region', { name: 'Catalog' });
  await expect(catalog.getByRole('status')).toHaveText('3 products found');
  await page.getByLabel('Search products').fill('NOTEBOOK');
  await page.getByRole('button', { name: 'Search', exact: true }).click();
  await expect(catalog.getByRole('status')).toHaveText('1 products found');
  const results = catalog.getByRole('listitem');
  await expect(results).toHaveCount(1);
  await expect(results.getByRole('heading')).toHaveText('Notebook');
  await expect(results.getByText('SEK 12.00', { exact: true })).toBeVisible();
});

Pass when: explain every assertion. No tests found often means path/project mismatch.
