Step 10: AI review and early guardrails

Why this lesson is here. The AI review. You defend the assertion.

Outcome: supervise AI and catch common mistakes early. Lint cannot prove correctness.

Study: unhandled Promises, Playwright lint.

eslint.config.mjs, checking test files:

import tseslint from 'typescript-eslint';
import playwright from 'eslint-plugin-playwright';

export default [{
  files: ['tests/**/*.ts'],
  languageOptions: {
    parser: tseslint.parser,
    parserOptions: { projectService: true, tsconfigRootDir: import.meta.dirname },
  },
  plugins: { '@typescript-eslint': tseslint.plugin, playwright },
  rules: {
    '@typescript-eslint/no-floating-promises': 'error',
    'playwright/no-wait-for-timeout': 'error',
    'playwright/prefer-web-first-assertions': 'error',
  },
}];

Prompt: "Use only this contract, manual case, and markup. Identify the oracle first. Propose one small test with awaited actions/web assertions. No invented selectors, fixed sleeps, or guessed rules. List questions. I will review and execute it."

Pass when: tests need no runtime AI and you defend their assertions.
