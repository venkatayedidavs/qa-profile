Step 18: Create the approval script

Progress is saved in this browser.

0%

Why this lesson is here. The supplied script comes after the event model, so you can read its decisions.

Create: scripts/approval-hook.cjs. The .cjs extension uses CommonJS modules. The explicit copilot or local argument selects the input and output format; it does not guess the runtime from untrusted data.

const fs = require('node:fs');

const harness = process.argv[2];
if (!['copilot', 'local'].includes(harness)) {
  process.stderr.write('Expected harness: copilot or local.\n');
  process.exit(2);
}

let event;
try {
  event = JSON.parse(fs.readFileSync(0, 'utf8'));
} catch {
  event = null;
}

const isObject = event !== null && typeof event === 'object';
const isCopilotEvent = isObject
  && typeof event.toolName === 'string' && event.toolName.trim() !== ''
  && Object.hasOwn(event, 'toolArgs');
const isLocalEvent = isObject
  && event.hook_event_name === 'PreToolUse'
  && typeof event.tool_name === 'string' && event.tool_name.trim() !== ''
  && event.tool_input !== null && typeof event.tool_input === 'object'
  && !Array.isArray(event.tool_input);
const valid = harness === 'copilot' ? isCopilotEvent : isLocalEvent;

const decision = {
  permissionDecision: valid ? 'ask' : 'deny',
  permissionDecisionReason: valid
    ? 'Practice lab: review this tool request before continuing.'
    : 'Invalid tool event. Check the selected harness and hook config.',
};

const output = harness === 'local'
  ? { hookSpecificOutput: { hookEventName: 'PreToolUse', ...decision } }
  : decision;
process.stdout.write(`${JSON.stringify(output)}\n`);

Read the program: validate the selected format, parse stdin as JSON, check the fields used by this exercise, choose ask or deny, serialize one response. It does not log arguments, read transcripts, run a shell, or call a model. This is a small teaching check, not a full event-schema validator or a production policy engine.

Offline trial, macOS/Linux: this fixed sample describes a request; it does not run the named tool. On any supported OS, the test suite in Step 19 supplies input without needing shell piping.

printf '%s' '{"toolName":"view","toolArgs":{}}' | node scripts/approval-hook.cjs copilot

Expect one JSON object with permissionDecision: "ask". No editor approval dialog appears in a standalone terminal trial because no harness is interpreting the result. Running the script without piped input waits for stdin; use the tests instead.

Pass when: you can explain the script without assuming that printing JSON already controls the editor.
