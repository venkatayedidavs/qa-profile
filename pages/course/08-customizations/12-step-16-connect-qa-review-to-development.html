Step 16: Connect QA review to development

Progress is saved in this browser.

0%

Why this lesson is here. The phase gate connects review to a code change only after the tool boundary holds.

Seed a local defect: manually change only quantity <= 5 to quantity < 5. Keep the contract and tests unchanged. Run the quantity tests: the case for 5 must now fail. Label this as a deliberate teaching defect, not a discovered production bug.

QA task: ask the reviewer for the violated requirement and a reproducible finding. Development task: ask a general assistant to explain the smallest repair, without applying it. Verify the explanation, restore <=, and rerun the tests yourself.

Pass when: the correct tests detect the seeded defect and pass after the product code is restored.
