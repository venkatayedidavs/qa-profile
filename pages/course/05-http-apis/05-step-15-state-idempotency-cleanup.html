Step 15: State, idempotency, cleanup

Why this lesson is here. Stateful cart writes come after single-call contracts. Cleanup is the phase gate.

Outcome: create, change, read afresh, clean up despite failure. Repeating this PUT must not duplicate/increment quantity.

Study: setup/teardown, PUT. The .js import extension is intentional with NodeNext TypeScript.

tests/api/cart.spec.ts

import { test, expect } from '@playwright/test';
import { cartSchema } from '../../src/schemas/shop.js';

test('CART-02: setting quantity is idempotent', async ({ request }) => {
  const headers = { Authorization: 'Bearer learner-alex' };
  const created = await request.post('/api/carts', { headers });
  expect(created.status()).toBe(201);
  const cart = cartSchema.parse(await created.json());
  try {
    for (const quantity of [2, 2]) {
      const updated = await request.put(`/api/carts/${cart.id}/items/p1`, {
        headers, data: { quantity },
      });
      expect(updated.status()).toBe(200);
      expect(cartSchema.parse(await updated.json()).totalCents).toBe(2400);
    }
    const read = await request.get(`/api/carts/${cart.id}`, { headers });
    expect(read.status()).toBe(200);
    const saved = cartSchema.parse(await read.json());
    expect(saved.items).toEqual([
      { productId: 'p1', quantity: 2, unitPriceCents: 1200 },
    ]);
    expect(saved.totalCents).toBe(2400);
  } finally {
    const removed = await request.delete(`/api/carts/${cart.id}`, { headers });
    expect(removed.status()).toBe(204);
  }
  const missing = await request.get(`/api/carts/${cart.id}`, { headers });
  expect(missing.status()).toBe(404);
});

Pass when: independent tests and unchanged rejected state; distinguish read-after-write from database durability.
