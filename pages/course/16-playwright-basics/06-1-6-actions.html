1.6 Actions

Why this lesson is here. What you do with a locator, before the waiting rules those actions trigger.

await locator.click();            await locator.dblclick();
await locator.fill('text');       await locator.clear();
await locator.check();            await locator.setChecked(true);
await locator.selectOption('Red');
await locator.setInputFiles('invoice.pdf');
await locator.hover();            await locator.dragTo(target);
await page.keyboard.press('ControlOrMeta+S');

fill() sets the value in one operation and is the default choice. pressSequentially() types character by character and is only for inputs with special key handling, such as autocomplete widgets that react to each keystroke.

When would you use pressSequentially() instead of fill()?

Only when the application reacts to individual key events — typeahead search, input masks, character counters driven by keydown. Otherwise fill() is faster and less flaky. The old type() method is deprecated.
