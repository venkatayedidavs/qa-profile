Step 21: Understand MCP before connecting anything

Progress is saved in this browser.

0%

Why this lesson is here. MCP last. The page explains the protocol before you connect a server.

Mental model: an AI application is an MCP host, with a client connection to each server. A server can offer executable tools, contextual resources, and reusable prompts. It can run locally or remotely. A locally launched server can still access files or the network.

Practice without installation: draw this data flow and choose only the capability needed to summarize a synthetic issue. Built-in file and browser tools may already solve a local task; MCP is not mandatory. This table is an architecture exercise, not a running MCP server.

Pass when: you can explain the data and permission boundary before installing a server or granting access.
