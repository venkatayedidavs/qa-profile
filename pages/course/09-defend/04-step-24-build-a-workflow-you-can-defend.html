Step 24: Build a workflow you can defend

Progress is saved in this browser.

0%

Why this lesson is here. The final AI gate: a workflow you can defend, including when ordinary code is enough.

Independent capstone: create a new synthetic requirement: "A discount percentage must be a number that is an integer from 0 to 50 inclusive; reject all other values without coercion; return a boolean." Keep the original quantity contract unchanged. Choose your own cases and write expectations before using AI.

  1. Attempt the case design without AI and record the time and gaps.
  2. Use your reusable skill with the new requirement. Review every suggestion against your own oracle.
  3. Adapt the reviewer to explicitly reference the new files, preserving its tool restrictions. Review any proposed implementation before executing it.
  4. Run deterministic tests, introduce and restore one controlled defect, and preserve real evidence.
  5. Compare total effort, corrections, missed risks, and unsupported findings. Account for familiarity with the task; this small comparison does not prove a general productivity gain.

Pass when: you can defend the result and identify when ordinary code or a human review is enough. Keep evidence local until a privacy review; this is project learning, not proof of professional AI experience.
