2.1 TypeScript

Why this lesson is here. The bank follows the plan's phase order. Language is the first block, matching the first exit criterion.

Why TypeScript for test automation rather than plain JavaScript?

Tested: whether you chose the language or inherited it.

Compile-time feedback on page-object and fixture contracts, IDE discoverability of a large API, safe refactoring across a big suite, and typed test data that prevents invalid states being constructed. Name the cost honestly: build configuration, and a learning curve for manual testers joining the suite.

What is the difference between interface and type?

Interfaces are open to declaration merging and read naturally for object shapes; type aliases express unions, intersections, mapped and conditional types. The distinction matters less than consistency — say which convention your team picked and why.

Where have you used generics in a test framework?

A typed API client where the response type is a parameter; typed data builders; and test.extend<TestFixtures, WorkerFixtures>, where the two parameters separate test-scoped from worker-scoped fixture types so the runner knows which lifetime to give each.

What goes wrong if you forget an await?

The promise floats. The action or assertion never completes within the test, so a test can pass while doing nothing, and the failure surfaces later as an unhandled rejection attributed to an unrelated test. Prevention is tooling, not discipline: the @typescript-eslint/no-floating-promises rule plus tsc --noEmit as a pipeline gate.

unknown versus any?

any disables checking and spreads through the codebase; unknown forces you to narrow before use. Parse API responses into unknown and narrow, or type the request call generically so the response is typed at the call site.

Quick-fire: optional chaining and nullish coalescing; readonly and as const; enum versus union of string literals; Partial, Pick, Omit, Record; why Promise.all on locator actions is usually wrong; how tsconfig path aliases are resolved by the runner.
