Step 20: Verify live approval and disable cleanly

Progress is saved in this browser.

0%

Why this lesson is here. The live check is last, and the lesson includes disabling the hook cleanly.

Activate only in the practice lab: after reviewing the script and passing the tests, copy the chosen configuration's contents to .github/hooks/review.json. Create that folder in the lab if needed. Do not install both configurations or overwrite an existing policy file.

  1. Select the matching session target and inspect Hooks in Chat: Open Customizations. For Local, the workspace must be trusted and chat.useHooks enabled; that setting does not configure Agent Host hooks.
  2. Start a new session and ask the agent to read the synthetic quantity contract using a file-read tool.
  3. Inspect the hook event and approval request. Deny once; verify the proposed read did not execute. Retry and approve only that single harmless read; verify its actual result.
  4. Rename the lab's review.json to review.json.disabled, start another fresh session, and verify that this lab hook is no longer discovered. Keep normal approval controls and managed policies intact.

If blocked: inspect the selected target, active file location, Node availability, working directory, and event format. Local exposes the GitHub Copilot Chat Hooks Output channel; also inspect available Agent Debug Logs. If the expected approval is absent, stop and record the live check as unverified. Do not try a consequential action as a substitute test.

Limits: this intentionally noisy demo is not a sandbox, secret filter, or complete security policy. It does not intercept commands you type manually or every network request. Other hooks and policies may also affect the decision. Copilot documents hook timeouts falling through to normal permissions; Local has different exit-code handling. A broken hook is not a dependable safety barrier. Never let an agent silently rewrite a hook it will later execute.

Pass when: observed behavior matches the selected runtime. Offline tests alone do not earn a live-integration pass.
