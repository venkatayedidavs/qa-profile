Step 2: Give useful context

Progress is saved in this browser.

0%

Why this lesson is here. A specific prompt comes after you know a fluent answer is not evidence.

Understand: "test my cart" omits the rule, scope, and expected output. A better prompt names all three. Files are not necessarily in context just because they exist in a repository.

Task: propose tests, not code changes.
Requirement: quantity must be a number that is an integer from 1 to 5.
Reject other inputs without converting their type. Return a boolean.
Scope: this function only; no UI, HTTP, stock, or discount assumptions.
Output: input, expected boolean, requirement, and risk covered.
List questions separately. Do not claim to have executed tests.

Read: prompt engineering and output variability. The principles apply here; no API setup is required.

Pass when: you can explain why adding relevant context helps but does not guarantee a correct answer.
