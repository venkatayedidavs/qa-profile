Three things get mashed into one word, and this lesson pulls them apart.

The model generates an output from its input. A fluent paragraph proves only that a model produced text.

The product, for this course GitHub Copilot in the editor, supplies the interface, the context handling, and the tools around the model. Changing the model does not change a hook's runtime format. A custom agent is a role and a tool list, not a newly trained model.

Your responsibility is the third part. A plausible test report is not evidence that a command ran, or that a test passed. You accept an answer only with independent evidence: a command you ran, a diff you read, or a contract id you checked.

Name one task a model might help with, and name the evidence you would need before you trust it. You are done when you can separate a suggestion, an action that actually executed, and a result you verified.
