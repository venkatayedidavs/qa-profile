what is RAG:
RAG stands for Retrieval-Augmented Generation, an AI framework that improves the accuracy and reliability of Large Language Models (LLMs) by letting them look up facts from an external knowledge base before generating a response.

What is Threat modelling:
Threat modeling = mapping how a system's parts and data connect, then spotting design-level security weak points — like missing auth checks, broken access control, or unsafe data flows — before the code ships. It's not bug-scanning; it's checking the architecture itself for risk.

Software built WITH AI help (Copilot/Claude writing code for a traditional app) — the product is still deterministic software.
Software that IS AI (ML models, LLM-powered features, agents) — the product itself is probabilistic.
